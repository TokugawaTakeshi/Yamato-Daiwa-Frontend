# Yamato Daiwa Frontend — React

The adaptation of [Yamato Daiwa Frontend](https://www.npmjs.com/package/@yamato-daiwa/frontend) toolkit for the frontend
  development to [React framework](https://react.dev/).

This adaptation package provides only React-specific functionality.
The [core package](https://www.npmjs.com/package/@yamato-daiwa/frontend) is still required as the peer dependency to 
  get the styles.


## Installation

```bash
npm i @yamato-daiwa/frontend-react@2.0.0 @yamato-daiwa/frontend@2.0.0
```

### Peer Dependencies

+ **@yamato-daiwa/frontend**: @2.0.0
+ **react**: ~19.2.0
+ **react-dom**: ~19.2.0
+ **react-router**: ~7.11.0
