# Yamato Daiwa Frontend — Blazor

The adaptation of [Yamato Daiwa Frontend](https://www.npmjs.com/package/@yamato-daiwa/frontend) toolkit for the frontend
  development to C# language and [Blazor framework](https://dotnet.microsoft.com/en-us/apps/aspnet/web-apps/blazor).

This adaptation package provides only Blazor-specific functionality.
The [core package](https://www.npmjs.com/package/@yamato-daiwa/frontend) is still required to be installed by 
  [npm](https://www.npmjs.com/) to get the styles.


## Installation
### .NET

```shell
dotnet add package YamatoDaiwaFrontend --version 2.0.0
```

### npm

```shell
npm i @yamato-daiwa/frontend@2.0.0 -E
```

The version of the npm package must be even with .NET one.
